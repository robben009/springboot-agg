# 错误码

## 规则

错误码使用 `模块_编号` 格式。新增业务错误必须在本文件登记，并在测试中覆盖对应错误分支。

## 通用错误

| 错误码 | HTTP 状态 | 说明 |
| --- | --- | --- |
| `OK` | 200 | 请求成功 |
| `SYS_400` | 400 | 请求参数错误 |
| `SYS_404` | 404 | 资源不存在 |
| `SYS_409` | 409 | 数据状态冲突 |
| `SYS_500` | 500 | 系统内部错误 |

## 认证授权

| 错误码 | HTTP 状态 | 说明 |
| --- | --- | --- |
| `AUTH_401` | 401 | 未登录或登录已过期 |
| `AUTH_403` | 403 | 无访问权限 |
| `AUTH_1001` | 401 | 用户名或密码错误 |
| `AUTH_1002` | 403 | 账号已停用 |

## 用户

| 错误码 | HTTP 状态 | 说明 |
| --- | --- | --- |
| `USER_1001` | 404 | 用户不存在 |
| `USER_1002` | 409 | 用户名已存在 |
| `USER_1003` | 400 | 用户状态非法 |

## 项目

| 错误码 | HTTP 状态 | 说明 |
| --- | --- | --- |
| `PROJECT_1001` | 404 | 项目不存在 |
| `PROJECT_1002` | 403 | 无项目访问权限 |
| `PROJECT_1003` | 409 | 项目状态不允许当前操作 |
| `PROJECT_1004` | 400 | 搜索条件非法 |

## 审批

| 错误码 | HTTP 状态 | 说明 |
| --- | --- | --- |
| `APPROVAL_1001` | 404 | 审批模板不存在 |
| `APPROVAL_1002` | 404 | 审批实例不存在 |
| `APPROVAL_1003` | 403 | 用户无审批权限 |
| `APPROVAL_1004` | 409 | 审批状态冲突 |

| `BILLING_1001` | 404 | 套餐不存在 |
